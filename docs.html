Add Critterkit to your app.

Two lines get you a mascot that notices what's happening and reacts by itself. Everything on this page is optional.

Install

Paste these before the closing </body> tag. Swap in your mascot's id from the paint page, or leave mascot out to use the drawn mascot.

<script src="https://www.critterkit.com/critter.js"></script>
<critter-mascot mascot="your-mascot-id" autopilot greet></critter-mascot>

autopilot lets the mascot float in a corner and react to your app. greet makes it say hello when the page loads.

React and Next.js

Critterkit is a standard web component, so the tag works in React, Vue, Svelte and plain HTML. Load the script once, then use the tag like any other element.

Next.js

// app/layout.tsx
import Script from 'next/script'

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>
        {children}
        <critter-mascot mascot="your-mascot-id" autopilot="" greet="" />
        <Script src="https://www.critterkit.com/critter.js" strategy="afterInteractive" />
      </body>
    </html>
  )
}

In React, write switches like autopilot="" rather than just autopilot, so they're always passed through to the tag.

TypeScript

To stop TypeScript complaining about an unknown tag, add this once anywhere in your project:

declare namespace JSX {
  interface IntrinsicElements { 'critter-mascot': any }
}

iOS (Swift)

The same mascot runs in native iPhone apps, on top of SwiftUI or UIKit. It needs iOS 15 or later.

Add the package

In Xcode: File → Add Package Dependencies…, paste this address, and add CritterKit to your app target.

https://github.com/corylarro/CritterKit

SwiftUI

import CritterKit

// on your root view
ContentView()
  .critterMascot(.init(mascotID: "your-mascot-id"))

UIKit

// once your window is showing
Critter.start(.init(mascotID: "your-mascot-id"))

Point, cheer and react

Name views so the mascot can walk to them, then point or celebrate:

TextField("Email", text: $email).critterTarget("email")

Critter.point(at: "email", say: "That email looks off.")
Critter.celebrate(at: "streak", say: "7 days in a row!")
Critter.react(.love)
Critter.say("Hi!")

// reacts to a network call: thinks, then cheers or looks worried
try await Critter.watch(success: "Saved!") {
  try await api.save(note)
}

// walk people through a screen
Critter.tour([("feelings", "Tap how you feel today."),
              ("session", "Then start tonight's session.")])

On iOS the mascot sits above the keyboard while people type, covers its eyes on password fields, and says welcome back when someone returns to the app. Options for Critter.Configuration: mascotID, corner, offset, size, greets, greeting, autopilot, hideable, sleepAfter, seasonal.

Placement and size

The mascot sits in the bottom-right corner by default. Move it if something else lives there.

<critter-mascot autopilot position="bottom-left" offset="24 90" size="small" mobile-size="80"></critter-mascot>
  • position: bottom-right, bottom-left, top-right or top-left.
  • offset: distance from the edges in pixels, sideways then up or down. One number sets both.
  • size: small, medium, large, or a width in pixels. mobile-size applies on screens narrower than 600px.
It steps aside by itself. If a chat bubble, cookie banner or anything else is pinned in its corner, the mascot stands on top of it, even when it loads a few seconds later. Turn this off with avoid="false".

Living in a spot on the page

Instead of floating in a corner, the mascot can live inside an element, like a hero section, and step out when it needs to. Point dock at the element, or leave it empty to use the tag's parent.

<div id="pip-home" style="height:280px"></div>
<critter-mascot mascot="your-mascot-id" dock="#pip-home"></critter-mascot>

What autopilot notices

With autopilot on, the mascot watches the page and your app's network requests. You don't wire anything up.

  • Someone types in a field: the mascot watches, and covers its eyes for passwords.
  • A form won't submit: the mascot walks to the missing or invalid field and points at it.
  • A request is slow, succeeds or fails: the mascot thinks, cheers or looks worried.
  • An error message appears on the page: the mascot points it out.
  • Someone taps a button over and over: the mascot calms things down.
  • Someone comes back to the tab, or the connection drops and returns.
  • On phones, the mascot sits on top of the keyboard so it stays in view.

Moments only your app knows about, like a streak or a milestone, need one line. That's the next section.

Make the mascot react

Grab the element and call any of these.

const pip = document.querySelector('critter-mascot')

// celebrate next to an element, then walk home
pip.goTo(streakCard, { mode: 'sit', state: 'success', text: '7 days in a row!' })

// quick reactions where the mascot already is
pip.react('love', 2000)
pip.say('Saved!', { hold: 1500 })
MethodWhat it does
goTo(el, options)Walks to an element. mode is 'point' (stand beside it and point, the default) or 'sit' (sit on top of it). Optional state and text. Walks home afterwards unless stay: true.
point(el, text)Shortcut for walking over and pointing at something.
react(name, ms)Shows a reaction for a moment, then goes back to normal.
setState(name)Holds a state until you change it, for example 'thinking' while something loads.
say(text, { hold })Shows a speech bubble. hold is how long it stays, in milliseconds.
tour(steps, { done })Walks people through a screen. Pass [{ target: '#plan', text: 'Pick a plan' }, …] and the mascot points at each one in turn, says the text, then heads home. done is an optional last line. stopTour() ends it early.
home()Walks back to its corner or spot.
lookAt(x, y)Looks toward a point on the screen.
cover(true)Covers its eyes. cover(false) uncovers them.

Reactions and states: idle, thinking, success, error, surprised, confused, love, wave, talking, sleeping, dance (a little dance with music notes, for big wins), sad (slumps under a tiny rain cloud, for empty states) and peek (ducks down so only its head shows, then pops back up).

Seasonal touches. Little effects drift around the mascot by date, without changing how it looks: falling leaves in November, snow in December, confetti on New Year's, hearts before Valentine's Day and bats the week before Halloween. Turn them off with seasonal="off", or pick one with seasonal="snow" (also leaves, confetti, hearts, bats). In Swift, set seasonal: false in the configuration, or call The mascot.season(.snow).

Moments

Ready-made celebrations for the things that matter in your app. Each one picks the right animation, effects and words, and you can swap in your own line with say.

const pip = document.querySelector('critter-mascot')

pip.moment('first-purchase')
pip.moment('streak', { count: 7 })
pip.moment('milestone', { say: '100 notes written!', at: '#notes' })

Available moments: first-purchase, purchase, streak (with count; bigger celebrations at 7, 30, 100 and other milestones), milestone, level-up (optional count), goal, welcome, welcome-back, empty and oops. Add at (an element or selector) to have the mascot walk over and celebrate right there.

On iOS: Critter.moment(.firstPurchase), Critter.moment(.streak(days: 7)), Critter.moment(.milestone, say: "100 notes!", at: "notes").

With autopilot on, the mascot also nudges people who start a form and then pause or head for another tab: it walks to the next empty field and says how many are left.

Moments without code

On websites, you can set up moments on your mascot’s page at critterkit.com/mascots instead of writing code. Pick when it happens and what the mascot does:

  • Someone visits a page, like /thank-you. Use * for any, like /blog/*.
  • Someone taps a button or link whose text contains what you type, like Upgrade.
  • Some words appear on the page, like Order confirmed.

Then it plays a moment, says something, points at a button or link, or plays a custom moment from the studio. Each one can run once per visitor or every time. Changes reach your site within a minute. To turn them off on a page, add no-rules to the tag. Listen for pip:rule to see when one runs.

Choreography

String moves together with play. The easiest way is the custom moments studio: tap moves, moods, effects and words together, watch your mascot play it, then copy the code.

pip.play([
  { do: 'flip' },
  { do: 'react', state: 'dance', ms: 2500 },
  { do: 'say', text: 'Level 5!' },
  { do: 'emote', kind: 'spark' }
])

Moves (each waits until it's done): jump, bigjump, flip, spin, shake, grow, poof (vanish and reappear, with to: home, center, left, right, random or a selector), goto (with target), moment and wait. These start and keep going while the next step runs: react (a mood, with state and ms), say, emote (spark, note, dust, bang, sweat, smoke, drops, confetti, hearts) and prop (hold up any emoji, like { do: 'prop', emoji: '🍕' }).

Fill in values that change each time with {placeholders} in what it says: pip.play([{ do: 'say', text: 'Level {level}!' }], { level: user.level }).

On iOS: Critter.play([["do": "flip"], ["do": "say", "text": "Level {level}!"]], values: ["level": level]).

Events

pip.addEventListener('pip:autopilot', e => console.log(e.detail.action, e.detail.signal))
EventWhen it fires
readyA painted mascot has finished loading.
errorA painted mascot couldn't load. A good moment to fall back to the drawn one.
statechangeThe mascot changes state. detail.state says which.
pip:autopilotAutopilot noticed something. detail.action is what the mascot did, detail.signal is what it saw.
pip:hide, pip:showA visitor hid the mascot or brought it back.

Letting visitors hide the mascot

A floating mascot has a small close button: it shows on hover, or after a tap on phones. Hidden, the mascot becomes a small button in its corner that brings it back. The choice is remembered on your site.

To remove the close button, add no-hide. You can also call pip.hideMascot() and pip.showMascot() yourself, for example from a settings page.
