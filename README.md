# Pip

Interactive, auto-rigged mascots for web apps.

- `index.html`: the demo (mascot builder + live autopilot demo)
- `pip-mascot.js`: the one-file embed
- `embed-test.html`: a plain page that only adds the two embed lines

```html
<script src="/pip-mascot.js"></script>
<pip-mascot autopilot greet></pip-mascot>
```
